# tare — before / after, episode 7

One business, two designs, and a button that crossfades between them.

**The after is a pixel-perfect rebuild of the reference's home page. The only thing that
changed is the words.** Same illustrations, same arrangement, same colours, same
typefaces, same interaction — rule 0 of [the series](../README.md). The *before* is
invented, under rule 3.

**tare** is an invented accountancy practice for freelance creatives. The firm, the
services and the figures are not real, and nothing here is tax advice.

## The page's one idea

**The Tax Man is thirteen drawings and a click.** He starts as himself, and each click puts
him in another disguise — a paper bag, a clock face, a traffic cone, arrows through the
head, a moustache and glasses. A hand-lettered label beside him says so, and the cursor
over him is a drawn pointing hand rather than a system pointer.

Nothing else on the page moves. That is exactly why it lands: it is the only interactive
thing in the design, and it is a joke rather than a feature. It is rebuilt as a real
`<button>` with a live label, so it is reachable by keyboard and announces which of the
thirteen you are on — the reference's version is a `div` and is not.

The second idea is the **"Who it's for" pile**: the section pins for four screens and deals
six cards, each rotated and offset, onto a 128px heading that never leaves. The question
gets buried by its own answers.

## The hovers

| Element | Rest → hover |
|---|---|
| Nav links | ink → 60% ink |
| Outlined buttons | transparent → filled forest, text to cream |
| Filled buttons | forest → 85% forest |
| "Meet the team" | mint outline → mint fill, text to forest |
| Footer links | plain → underlined |
| **The Tax Man** | the *cursor* changes to a drawn hand. The drawing itself only changes on a **click** |

That last row is the one worth stating: photographing the figure's hover produces two
identical frames, and that is correct. The reference puts its whole interaction behind a
click and spends the hover on the cursor.

## Declared departures

1. **A third-party award badge on the right edge is not rebuilt** — it is a widget, not the
   design.
2. **The copy is invented throughout**, written to the reference's lengths. The headline is
   two lines in both.
3. **No typeface substitutes** — see [`CREDITS.md`](./src/assets/img/CREDITS.md).
4. **The page is 6% shorter**, almost all of it in the pinned "Who it's for" section, where
   the reference pins for 3,722px and this build pins for 420vh.

## This episode's before

A small professional-services site built in about 2009 and never touched since. Every
heading, the wordmark, the strapline, the introduction and the fee table are **image
files**, generated by [`tools/bake-before.py`](./tools/bake-before.py) — which is the only
way to change a word of them, which is exactly the position the client was in.

It is not a careless page: a print designer was given a web page and solved it the way
print is solved. Everything wrong with it follows from that one decision — nothing is
selectable, searchable or resizable, **there are no headings in the document at all**, and
every image carries its own baked cream background, so the wordmark sits on the navy header
band as a pale rectangle.
