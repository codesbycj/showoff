# Image credits

**These are not original assets, and they are not free-licensed.**

Every file in this folder was downloaded from the reference site this study was
measured against, <https://switchblade-awwwards.vercel.app>, and re-encoded as
WebP at the sizes this page actually paints. That is a deliberate exception to
the rule in `websites/README.md` that each project supplies its own
free-licensed photography and credits it — taken so the motion could be checked
against the reference frame for frame rather than against stand-ins.

The consequence: this project is a private motion study. Do not deploy it, and
replace this folder before it goes anywhere public.
