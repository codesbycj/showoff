# Asset credits

**`flags.mp4` and `flags-poster.webp` are not original assets, and they are not
free-licensed.**

Both were downloaded from the reference this study was measured against,
<https://pensatori-irrazionali.com>, from
`assets.pensatori-irrazionali.com/v1/static/`:

| File | Source | Size |
|---|---|---|
| `flags.mp4` | `/videos/flagsOptimized.mp4` | 4.98MB, 2560x1440, 4.96s, looping |
| `flags-poster.webp` | `/images/flags-poster-lossless.webp` | 2560x1440 |

They are a 3D render of printed ribbons carrying the logos of that studio's own
clients. Nothing in this repository has any relationship with those brands, and
the render is not ours.

This is a deliberate exception to the rule in [`../../../../README.md`](../../../../websites/README.md)
that every project supplies its own free-licensed imagery and credits it —
taken for the same reason `switchblade/` and `bulwark/` take it: the study is of
a *displacement field applied to this footage*, and the field is only checkable
against the reference if it is sampling the same pixels. With stand-in footage
there would be nothing to compare, and the one thing worth getting right — how
far the fabric moves under the cursor — would be unverifiable.

The consequence: **this project is a private motion study. Do not deploy it**,
and replace this folder before any of it goes anywhere public. The brand name,
the mark, the copy and the page furniture around the render are all invented,
so the only thing that has to be swapped is these two files.
