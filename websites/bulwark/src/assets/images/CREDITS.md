# Image credits

**These are not original assets, and they are not free-licensed.**

Every file in this folder was downloaded from the reference site this study was
measured against, <https://huyml.co>, where they are the portfolio's own
project photography. That is a deliberate exception to the rule in
`websites/README.md` that each project supplies its own free-licensed imagery —
taken for the same reason `switchblade/` takes it, and declared the same way.

The reason is specific to what this study is about. The home page is a 3D
collage: the motion *is* plates of a certain shape and weight sweeping past a
camera on a diagonal. Substituting nineteen stand-ins changes what the motion is
being judged against, because the arrangement was measured off stills of these
exact plates in these exact positions. Abstract fills were tried first and are
what the earlier revision of this project shipped; they made the geometry
impossible to check.

The project names, descriptions, award lists and per-project colours in
`src/data/projects.ts` come from the same place — the site's own Framer CMS
payload, which is embedded in the page.

**The consequence: this project is a private motion study. Do not deploy it,**
and replace this folder and `src/data/projects.ts` before it goes anywhere
public.

The nineteen are listed in the order the build uses, which is the reverse of the
CMS order — see the note at the top of `src/data/projects.ts`.
