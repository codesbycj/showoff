# paytinstart — reference

The brief is a **design shot**: a three-phone board for "Paytin", a lime-and-black
finance app, with this screen as the first phone (onboarding).

The board was supplied in the chat and never written to disk, so there is no
`source.png` here. That costs nothing: a posed board is an inspo brief and is
not measured against (AGENTS.md, "Three kinds of reference") — the palette, the
type hierarchy and the order of the blocks are what was taken from it.

Two things in the board were corrected in the build, deliberately:

* **"Degital Banking"** — a typo in the headline. It reads "Digital Banking"
  here.
* The character illustration is a hand-drawn line artwork that cannot be
  recreated and must not be traced badly. It is rebuilt as the thing it is a
  picture of — a wallet, a card, coins and a pointing hand, drawn in
  `react-native-svg` in the same flat line-art style.
