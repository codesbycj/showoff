# lensastats — image credits

**No photographs.** Everything on this screen is interface — a bar chart, a
track with a hatched band, two pie charts and a legend — so everything on it
is drawn (AGENTS.md, "Draw the interface, photograph the picture").

The pie wedges are built from the shares themselves, each starting where the
last ended, so they close the circle exactly rather than being three arcs that
happen to look right.

The folder is kept so the showcase's asset path exists and `lock` has
something to track.
