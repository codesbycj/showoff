# paytinstart imagery

**None.** This showcase ships no image files.

The reference's hero is a hand-drawn line artwork of a character climbing out
of a wallet. A drawing cannot be recreated and must not be traced badly, and
free-licensed stock has no answer for a bespoke character in a bespoke style —
so it is rebuilt in the same flat dialect as `react-native-svg` paths in
`src/features/paytinstart/components/hero-art.tsx`, along with the four marks
scattered round it. Nothing here is a bitmap and nothing is hotlinked.
