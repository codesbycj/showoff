Six, because the roster is six. Every nurse on the board has their own face: the same
portrait twice in one list reads as the same person twice.

## Why these are photographs

The staff are people, and a face is a picture, not an icon (rule 8). The reference puts
photographs on its own staff list too. Initials on a coloured disc is a fallback state,
not a substitute.

**The patients have no portraits, and that is deliberate.** The reference shows none
either, and a ward list is read by bed and name — a face beside eighteen invented
diagnoses would be the one place this build looked like a record of real people.

Everything else is drawn: the Medivra mark, all thirty interface glyphs, the five
handover-flag glyphs, the four counter rings, the shift and load meters, the band dots and
the per-patient score trends.
