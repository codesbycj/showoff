## Why these are photographs

The header's team stack and the account row are people, and a face is a picture, not an
icon (rule 8). The reference has photographs in both places.

Three in the stack and one in the sidebar, four different people — the same face twice in
one stack reads as the same person twice.

## Why the products are not

A shirt, a mug or a candlestick at 12px in a table row is a *label*, not a picture: the
reference shows them as names only and so does this. Where a product does get a mark here
it is the catalogue's own name set in type, which is what the design does.

Everything else is drawn: the Selviq diamond, all eleven sidebar glyphs, the small info
glyph beside every heading, the hatched analytics band, the hourly heatmap, the
performance gauge and the revenue ring.
