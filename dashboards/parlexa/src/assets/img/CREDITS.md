reference's own photography, which is not redistributable. Square-cropped on the head and
resampled once to 240px, which covers the 44px account disc at 3x and every smaller one
above it.

rather than re-downloaded, so the build has no network dependency.

Six, because the friends board is six — five others and the learner. Each row gets its own
portrait: the same face twice in one list reads as the same person twice.

## Why these are photographs

The friends board and the classmate stacks are people, and a face is a picture, not an
icon (rule 8). The reference puts photographs in both places too. Initials on a coloured
disc is a fallback state, not a substitute.

Everything else is drawn: the Parlexa mark, all twenty-six interface glyphs, the stacked
area chart, the goal ring, every meter, the four-week calendar and the vocabulary bar.
